# 第2.5阶段：分计划执行

根据功能大纲小节数量计算计划数，分计划执行生成。

## 计划数量计算规则

- 计划数量 N = 功能大纲小节总数 ÷ 2（向上取整）
- 小节统计：统计功能大纲中所有二级标题（如2.1、2.2、5.1、5.2等）数量
- 分组原则：按一级章节分组，每组包含相近的功能模块

## 执行流程

```mermaid
flowchart TD
    A[统计功能大纲小节数量] --> B[计算计划数量N]
    B --> C[按一级章节分组]
    C --> D[生成分计划清单]
    D --> E[输出计划清单给用户确认]
    E --> F{用户确认}
    F -->|确认| G[开始执行计划1]
    F -->|调整| H[根据反馈调整计划]
    H --> E
    G --> I[完成计划1]
    I --> J{是否还有后续计划}
    J -->|是| K[等待用户确认后执行下一计划]
    K --> L[执行下一计划]
    L --> I
    J -->|否| M[PRD生成完成]
```

## 分计划执行规则

1. 每完成一个计划后暂停，等待用户确认
2. 用户确认后继续执行下一计划
3. 如用户要求调整，根据反馈修改后继续
4. 所有计划完成后，输出完整PRD文档
