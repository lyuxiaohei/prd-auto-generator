# Phase1-新增：业务逻辑清单解析

解析 logic-list-spec 输出的业务逻辑清单文档，提取关键信息构建 PRD 配置。

---

## 执行流程

```mermaid
flowchart LR
    A[读取业务逻辑清单] --> B[解析章节结构]
    B --> C[解析表格内容]
    C --> D[构建PRD配置]
```

---

## 具体操作

### 1. 读取业务逻辑清单文件

**输入文件：** `业务逻辑清单_V{版本}.md`

**必要章节检测：**
- HMW问题陈述（可选）
- 页面章节（H3标题）
- 功能用例表（必须）
- 关键字段数据来源表（必须）
- 状态流转表（可选）
- 页面导航关系（可选）

### 2. 解析章节结构

**提取模块层级：**

```markdown
## 一、{模块名} `V{版本}`
### 1.1 {页面名}（{filename}.html）
### 1.2 {页面名}（{filename}.html）
```

**提取内容：**
- 模块名称
- 页面名称列表
- 页面文件名列表
- 页面定位（如有）

### 3. 解析表格内容

**功能用例表解析：**

```markdown
| # | 场景 | 操作 | 预期结果 |
|---|------|------|----------|
```

提取字段：
- 场景名称
- 操作描述
- 预期结果描述

**关键字段数据来源解析：**

```markdown
| 字段 | 数据来源 |
|------|----------|
```

提取字段：
- 字段名称
- 数据来源描述
- 状态标记（如有）

**业务逻辑增强解析：**

```markdown
| # | 问题 | 确认结果 |
|---|------|----------|
```

提取字段：
- 问题描述
- 确认结果（建议答案）

**状态流转表解析：**

```markdown
| 当前状态 | 可执行操作 | 目标状态 | 执行者 |
|----------|-----------|----------|--------|
```

提取字段：
- 当前状态
- 可执行操作
- 目标状态
- 执行者

**跳转关系表解析：**

```markdown
| # | 页面A | 触发条件 | 页面B |
|---|-------|----------|-------|
```

提取字段：
- 源页面
- 触发条件
- 目标页面

## 解析规则

### 用例类型判断

| 操作关键词 | 用例类型 | 判断依据 |
|------------|----------|----------|
| 输入、填写、填写信息 | input | 输入类操作 |
| 选择、下拉、Tab切换、点击Tab | select | 选择类操作 |
| 点击按钮、点击提交、点击确认 | trigger | 触发类操作 |
| 弹出弹窗、弹出确认弹窗 | popup | 弹窗类操作 |
| 查看、显示、展示 | output | 展示类操作 |
| 校验失败、提示、Toast提示 | error | 错误提示类 |
| 多个连续操作 | multi-step | 多步骤流程 |

### 数据来源类型判断

| 数据来源关键词 | 来源类型 | 判断依据 |
|----------------|----------|----------|
| 用户操作、用户输入、用户填写 | user_input | 用户主动输入 |
| 用户选择、Tab选择、下拉选择 | user_select | 用户选择操作 |
| 系统生成、自动记录、自动生成 | system_gen | 系统自动生成 |
| 品牌商城后台、后台、API查询 | api | 后台API |
| 上一页面传入、上一页传入 | page_pass | 页面参数传递 |
| 前端实时计算、实时计算 | frontend_calc | 前端计算 |

## 与原型HTML分析结合

**结合时机：** Phase1完成后，调用原型HTML分析补充：

| 业务逻辑清单提取 | 原型HTML补充 |
|------------------|--------------|
| 输入项字段名 | 输入项属性（placeholder、maxlength、required） |
| 展示项字段名 | 展示项格式（价格格式、时间格式） |
| 交互操作 | 点击事件代码、跳转逻辑 |
| 流程步骤 | 条件分支代码 |
| 状态流转 | 状态切换代码 |
| 错误提示 | Toast/Alert文案 |

## 解析示例

**输入业务逻辑清单：**

```markdown
### 1.1 申请页（aftersales_apply.html）

#### 1.1.1 功能用例表

| # | 场景 | 操作 | 预期结果 |
|---|------|------|----------|
| 1 | 选择类型 | 点击"仅退款"或"退货退款" Tab | 选中项橙色背景白字（#ff6034→#ee0a24），底部显示对应说明 |
| 2 | 填写原因 | 点击下拉框选择申请原因 | 展示选项：质量问题/不满意/其他，选中后关闭下拉 |
| 3 | 上传凭证 | 点击"添加图片"按钮 | 打开图片选择器，最多3张，显示缩略图预览 |
| 4 | 提交申请 | 点击"提交申请"按钮 | 校验通过弹出确认弹窗，点击"确认"跳转进度页 |
| 5 | 校验失败 | 未选择申请原因点击提交 | Toast提示"请选择申请原因" |

#### 1.1.2 关键字段数据来源

| 字段 | 数据来源 |
|------|----------|
| 申请类型 | 用户操作 — Tab选择 |
| 申请原因 | 用户操作 — 下拉选择 |
| 凭证图片 | 用户操作 — 图片上传 |
| 申请状态 | 品牌商城后台售后管理 |
```

**解析输出配置：**

```json
{
  "page_name": "申请页",
  "page_file": "aftersales_apply.html",
  "use_cases": [
    {"scene": "选择类型", "operation": "点击Tab", "expected": "选中项橙色背景白字", "type": "select"},
    {"scene": "填写原因", "operation": "点击下拉框选择", "expected": "展示选项并关闭", "type": "select"},
    {"scene": "上传凭证", "operation": "点击添加图片", "expected": "打开图片选择器，最多3张", "type": "input"},
    {"scene": "提交申请", "operation": "点击提交按钮", "expected": "弹出确认弹窗→跳转进度页", "type": "multi-step"},
    {"scene": "校验失败", "operation": "未选择原因点击提交", "expected": "Toast提示", "type": "error"}
  ],
  "fields": [
    {"field_name": "申请类型", "data_source": "用户操作 — Tab选择", "source_type": "user_select"},
    {"field_name": "申请原因", "data_source": "用户操作 — 下拉选择", "source_type": "user_select"},
    {"field_name": "凭证图片", "data_source": "用户操作 — 图片上传", "source_type": "user_input"},
    {"field_name": "申请状态", "data_source": "品牌商城后台售后管理", "source_type": "api"}
  ]
}
```
