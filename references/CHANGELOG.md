# prd-auto-generator 技能版本更新日志

## V1.3.0 - 2026-03-23

### 新增功能

#### 流程图编写细则章节

新增完整的流程图编写规范，包含以下子章节：

| 子章节 | 说明 |
|--------|------|
| 绘制场景判定 | 明确何时必须绘制流程图（用户操作流程、状态流转、数据跨模块流转） |
| 流程图类型选择指南 | 补充 `flowchart TD`、`flowchart LR`、`stateDiagram-v2`、`sequenceDiagram` 四种类型 |
| 节点命名规范 | 详细定义起始/结束/操作/判断节点的格式规范及连接线标注规范 |
| 流程图与业务规则映射 | 明确流程图分支必须与业务规则表格一一对应，并提供映射示例 |
| 标准示例 | 新增完整的上传图片流程示例和状态机设计示例 |
| 流程图完整性检查 | 新增8项检查项清单 |

### 优化改进

#### 质量检查清单重组

将原有扁平列表重组为6个分类：

- 基础结构检查（6项）
- 命名规范检查（3项）
- 流程图专项检查（8项，新增）
- 内容一致性检查（5项）
- 数据与权限检查（3项）
- 输出格式检查（1项）

## V1.2.0 - 2026-03-23

### 新增功能

- 五级标题序号规则：每个页面章节内从1开始递增
- 章节标注清理规则：生成文档时移除所有【必须】【按需】等标注
- 文件名称版本号规范：输出文件名需包含版本号

### 优化改进

- 质量检查清单新增"五级标题有序号"检查项
- 质量检查清单新增"文档不含章节标注"检查项

## V1.1.0 - 2026-03-18

### 新增功能

- 章节标注说明：定义【必须】【按需】【系统标题下无内容】等标注含义
- 场景差异化模板：不同页面类型使用不同章节模板
- 数据流转说明定位：明确与输入项/输出项的边界区分

### 优化改进

- 标题编号格式规范：使用阿拉伯数字+点号格式
- 常见错误表格扩充

## V1.0.0 - 2026-03-18

### 初始版本

- 基于功能大纲、源码分析、需求文档规范自动生成PRD文档
- 支持四级层级结构：系统 → 模块 → 页面 → 功能
- 支持Mermaid流程图生成
- 支持业务规则与源码一致性检查
- 包含标准输出模板
