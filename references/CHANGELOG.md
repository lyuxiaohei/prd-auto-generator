## V2.0 - 2026-04-04

### 新增
- **模块化重构**：将SKILL.md（1022行）拆分为模块化文件结构
  - `prompts/` 目录：6个阶段提示词文件（phase0-4 + phase2.5）
  - `rules/` 目录：4个编写规则文件（流程图、源码分析、命名规范、章节生成）
  - `templates/` 目录：4个输出模板文件（头部、页面章节、尾部、业务规则表）
  - `validators/` 目录：2个校验文件（质量检查清单、常见错误对照表）
- **自动化校验脚本**：
  - `scripts/validate-prd.sh`：PRD文档格式校验
  - `scripts/check-consistency.sh`：功能大纲一致性校验
- **测试用例**：
  - `test-cases/simple-component.json`：简单组件测试
  - `test-cases/complex-flow.json`：复杂流程测试
  - `test-cases/state-machine.json`：状态机测试
- **V3.0示例文档**：`references/example-prd-output-v3.md`

### 更新
- **SKILL.md精简**：从1022行精简到约120行，改为索引式结构
- **删除重复文件**：移除根目录CHANGELOG.md，统一使用references/CHANGELOG.md
- **示例文件更新**：复制PRD-可视化编辑器-V3.0.md作为最新示例

### 测试
- 使用素材库源码（src/material-library.html）测试生成PRD-素材库-V1.4.md
- 验证流程图、状态机、业务规则完整生成

### 优化理由
- 模块化降低单文件复杂度，便于维护和扩展
- 校验脚本提升文档质量可控性
- 测试用例支持回归测试

## V1.6 - 2026-04-04

### 新增
- **分计划执行机制**：根据功能大纲小节数量计算计划数（N=小节数÷2），每完成一个计划暂停等待用户确认后继续
- **章节按需生成规则**：功能概述必须编写，其他子模块根据源码实际情况按需生成
  - 流程图：多步骤操作时生成
  - 业务规则：有校验规则时生成
  - 状态机设计：有状态字段时生成
  - 输入项说明：有配置项时生成
  - 错误提示文案：有错误提示时生成
  - 数据设计：有跨模块数据流转时生成
- **源码分析要点**：识别状态字段、流程步骤、业务规则的方法

### 更新
- SKILL.md 新增第2.5阶段：分计划执行流程
- SKILL.md 新增章节按需生成规则表和典型场景示例
- 功能大纲更新：去掉辅助线、公告、大背景图、标题、关联链接组件
- PRD-可视化编辑器-V3.0.md 完整生成，严格按功能大纲层级编写

### 优化理由
- 分计划执行提升文档质量可控性
- 按需生成避免简单功能过度设计
- 减少无效章节，提升文档可读性

## V1.5 - 2026-04-04

### 新增
- **Phase 0 功能大纲确认流程**：当功能大纲不存在时，自动分析源码生成功能大纲草案，输出给用户确认后继续生成PRD
- **纯HTML/JS项目分析方法**：针对无框架的纯前端项目，新增HTML结构分析、JavaScript逻辑分析、弹窗组件分析、组件配置分析、业务规则提取等方法
- **功能大纲格式规范**：
  - 使用中文数字（一、二、三...）作为一级标题
  - 组件配置面板各自独立标题（五、六、七...），不合并
  - 配置项使用表格呈现：配置项名称、配置类型、可选值/说明
  - 弹窗作为子标题放在对应组件配置面板下
  - 隐藏组件明确排除，不在大纲中展示
  - 新增业务规则摘要和功能确认清单章节
- **源码分析函数命名模式表**：识别render*、open*Modal、handle*、move*、delete*等函数类型

### 更新
- SKILL.md 新增第零阶段流程图和执行步骤
- SKILL.md 新增纯HTML/JS项目分析章节
- SKILL.md 新增功能大纲输出格式模板
- SKILL.md 新增功能大纲层级结构规范
- SKILL.md 新增功能大纲编写原则
- example-feature-outline.md 更新为新的结构化格式
- example-prd-output.md 更新为符合新规范的完整PRD示例
- prd-template-specification.md 补充完整章节结构示例

### 优化理由
- 支持无功能大纲时的自动化生成，提升技能自动化程度
- 提升功能大纲可读性，便于用户快速确认
- 组件配置独立章节，避免内容杂糅
- 明确隐藏组件排除规则，避免生成无用内容

## V1.4 - 2026-03-23

### 新增
- **三级层次结构**：页面功能需求采用三级层次结构，将功能点按维度归类为6大模块
  - 1. 功能概述
  - 2. 界面设计（页面原型、输出项说明）
  - 3. 业务逻辑（流程图、业务规则、状态机设计）
  - 4. 交互设计（输入项说明、交互说明、错误提示文案）
  - 5. 数据设计（数据流转说明、数据权限设计）
  - 6. 扩展功能（批量操作规则、操作日志要求）
- **场景差异化模板**：不同页面类型（列表页、详情页、表单页、弹窗/抽屉）使用不同的章节模板
- **数据流转说明定位**：明确数据流转说明与输入项/输出项的边界区分

### 更新
- SKILL.md 标准章节结构更新为三级层次结构
- SKILL.md 五级标题序号规则更新为1-6的三级层次结构
- prd-template-specification.md 示例页面补充完整章节结构
- prd-template-specification.md 修复编号格式错误

### 优化理由
- 结构清晰，便于查阅
- 可按需展开，不必每次都写13项
- 便于新人理解需求文档框架

## V1.3 - 2026-03-20

### 新增
- **字段标识命名规范**：字段标识统一使用下划线命名法（snake_case），全部小写，单词之间用下划线连接
  - 示例：`category_name`、`parent_id`、`created_at`
  - 禁止使用驼峰命名（camelCase）或帕斯卡命名（PascalCase）

### 更新
- 在"必须遵守"章节新增第1条"字段标识命名规范"
- 在"常见错误"表格新增"字段命名不规范"错误示例
- 在"质量检查清单"新增字段标识命名规范检查项

### 更新

### 标注清理列表
- `【必须】` → 生成文档时移除
- `【按需】` → 生成文档时移除
- `【系统标题下无内容】` → 生成文档时移除
- `【模块标题下无内容】` → 生成文档时移除
- `【仅标题，标题下无内容】` → 生成文档时移除
- `【仅标题，后续补充】` → 生成文档时移除
- `【除必须外，其余按需决定是否配置】` → 生成文档时移除
- `【必须，可留白后续补充】` → 生成文档时移除

## V1.0 - 2026-03-18

### 初始版本
- 基于项目功能大纲、源码分析和需求文档规范，自动化生成标准化产品需求文档
- 支持Mermaid流程图、业务规则定义、一致性检查等功能
- 标准章节结构：需求背景、需求分析、系统流程图、详细需求
- 四级层级结构：系统 → 模块 → 页面 → 功能
- 输入参数：功能大纲路径、规范文档路径、源码目录、输出路径
- 参考文档：prd-template-specification.md、example-prd-output.md、example-feature-outline.md

### 核心功能
1. 信息收集：读取功能大纲、解析需求规范、扫描源码结构
2. 模块分析：独立模块独立章节、关联模块判断拆分
3. 文档生成：标准章节结构、Mermaid流程图、完整功能描述
4. 一致性检查：功能范围、模块划分、参数限制
